# integrity-bench

Исследовательский стенд оценки уровня целостности файлов.

Определяет целостность файла как скаляр от 0.0 (полностью повреждён) до 1.0 (цел)
для пяти групп форматов: текстовые, исполняемые, архивы, изображения, видео.

## Требования

- Python 3.13+
- [Poetry](https://python-poetry.org/)

## Установка

```bash
poetry install
cp .env.example .env
```

## Структура проекта

```
sample/       # тестовая выборка (оригинальные файлы)
corrupted/    # повреждённые копии (генерируются скриптом)
reports/      # результаты и метрики
scripts/      # вспомогательные скрипты
src/          # исходный код
  config.py   # конфигурация (пути из .env)
  models.py   # модели данных
  types.py    # типы
  corruptor.py # симуляция повреждений
```

## Использование

Симуляция атаки на тестовую выборку:

```bash
poetry run python scripts/corrupt_sample.py
```

Результат: повреждённые файлы в `corrupted/`, метаданные в `reports/ground_truth.json`.
